# Sortern releases

Notarized downloads of [Sortern](https://yashkeshan.vercel.app/products/sortern), on-device AI mail sorting for Mac.

Download the latest `.dmg` from [Releases](../../releases/latest), open it, and drag Sortern to Applications. Requires macOS 27 on Apple Silicon and Apple Mail.

Each release lists a SHA-256 checksum. To verify a download:

```bash
shasum -a 256 Sortern-1.0.dmg
```

This repository holds binaries only. Setup guide: https://yashkeshan.vercel.app/products/sortern/guide
